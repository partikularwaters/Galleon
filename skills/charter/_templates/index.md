# Charter forms

These are reusable blanks to adapt, not active project agreements. Use the project's
existing form when adequate. Browse this list when locating a form; normal Charter
work follows SKILL.md and the selected guide without reading every template.
The linked guides explain choices and tradeoffs; each form owns its fields and
adaptation instructions. Proposed destinations are examples, not required paths.

| Blank form | Adapt for | Relevant guidance |
| --- | --- | --- |
| [Work agreement](work-contract.md) | A bounded task record at its existing owner | [Shape guide](../guide.md) |
| [Plan](plan.md) | A reviewable plan in the project's planning home | [Shape guide](../guide.md) |
| [Folder contract](CONTEXT.md) | A justified local CONTEXT.md defining responsibilities | [Shape guide](../guide.md) |
| [Record](record.md) | A consistently retrievable incident, finding, or other record | [Record-library example](../examples/record-library.md) |
| [Change impact](change-impact.md) | The actual source, consumers, and evidence limits of an edit | [Change-impact guide](../change-impact.md) |
| [Memory entry](memory-CONTEXT.md) | Capture/restore rules, often in memory/CONTEXT.md | [Memory guide](../memory-guide.md) |
| [Current state](memory-state.md) | Verified continuation at an existing or agreed state owner | [Memory guide](../memory-guide.md) |
| [Capture](capture.md) | An earned separate save procedure | [Memory guide](../memory-guide.md) |
| [Restore](restore.md) | An earned separate read-only recovery procedure | [Memory guide](../memory-guide.md) |
| [Procedure entry](memory-procedure-router.md) | A mode entry routing distinct recurring cases | [Routed-procedure example](../examples/memory-routed-procedures.md) |

After adoption, the project owns the resulting agreement and its maintenance.
This index grants no write authority and does not supply missing approval.
