# Charter illustrations

These filled examples explain possible arrangements and tradeoffs. They are
synthetic, not observed projects or proof that checks ran. Read one when it helps
explain a relevant choice; do not load the collection on every invocation. Existing
project agreements take precedence. The selected guide remains the place for
broader selection advice, while each illustration owns its concrete scenario.
