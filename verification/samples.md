# Representative verification examples

These are synthetic illustrations of selected earlier test categories. They are
not copied pilot artifacts, executable regression tests, or new observed passes.
They are a small representative selection, not a statistical 10% sample.

| Situation | Expected check or stopping behavior |
| --- | --- |
| No work boundary exists | Explain the consequential gap and show a small proposal. |
| Existing agreement covers the task | Use it without inventing another agreement. |
| A planning input changes | Reassess the affected plan before consequential execution. |
| Scaffold target already exists | Stop before replacing it. |
| Import moves a context record | Verify content, ownership, and referring links. |
| Verification passes | Report evidence without inventing human acceptance. |
| An unrelated skill has the same name | Stop and offer an explicitly chosen prefix. |
| A path contains spaces or Unicode | Preserve its exact value through supported operations. |
| Structural work is interrupted | Inspect partial writes and later edits before proposing recovery. |
| Captured content differs on resume | Report the discrepancy before relying on remembered status. |

The earlier engine enforced some of these checks in code. This edition's skills
instruct the agent to perform appropriate checks; optional enforcement tools are
not included in this draft.
